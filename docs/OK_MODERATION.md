# Wanderhaym Games — подготовка публикации в Одноклассниках

Дата технической проверки: 26 августа 2026 года.

## Что уже адаптировано в коде

- Платформа определяется по официальному параметру `vk_client=ok`.
- Инициализация выполняется через `VKWebAppInit`.
- Игровые миры открываются через `VKWebAppOpenApp` с существующими VK app ID.
- В OK запрещён fallback на `vk.ru`, `vk.com`, DonationAlerts и другие внешние сайты.
- Кнопка `W` и поддержка в OK ведут только во внутреннюю группу Wanderhaym:
  `https://ok.ru/group/70000050799953`.
- DonationAlerts и другие внешние ссылки в версии OK скрыты.
- Прогресс портала разделён по платформам: `wh.vk.*` и `wh.ok.*`.
- Прогресс синхронизируется между устройствами через поддерживаемые в OK события
  `VKWebAppStorageGet` и `VKWebAppStorageSet`.
- Старый локальный прогресс пользователей VK и web мигрирует в новое хранилище.
- Приложение не запрашивает профиль, e-mail, телефон, друзей или токен API.
- Firebase используется только для анонимного общего числа телепортаций; идентификаторы
  и персональные данные пользователей туда не записываются.

## Действия в кабинете перед заявкой

1. В панели существующего VK Mini App `54709580` включить «Опубликовать в Одноклассниках».
2. Привязать аккаунт разработчика OK через предложенную OAuth-проверку.
3. Подготовить к модерации группу поддержки Wanderhaym в OK:
   `https://ok.ru/group/70000050799953`.
4. Если появится отдельная внутренняя страница поддержки, переопределить её через
   `VITE_OK_SUPPORT_URL`; по умолчанию обе кнопки уже ведут в указанную группу.
5. Проверить аватар приложения: квадрат 576 × 576, JPEG/PNG, не белый фон, без теней,
   внешней обводки, скруглённых углов и отметок «New»/«Exclusive»; на изображении должно
   читаться название Wanderhaym.
6. Загрузить описание и скриншоты desktop, mobile web, Android и iOS.
7. Заполнить сведения о разработчике и контакты для претензий/поддержки.
8. Проверить возрастную маркировку и документы об авторских правах на графику, музыку,
   маскота и обложки игр.
9. Уточнить монетизацию: правила OK требуют платформенную монетизацию либо отдельное
   согласование промо-приложения. Внешняя DonationAlerts в OK намеренно отключена.
10. После появления OK-версии проверить все app ID через `VKWebAppOpenApp` в реальном
    Android/iOS клиенте, web и mobile web, затем отправлять заявку на модерацию.

## Описание для карточки и модератора

**Короткое описание:**

> Wanderhaym Games — интерактивная WebGL-кузня игровых миров. Разогревайте ядро,
> собирайте лапу-портал, путешествуйте по разным маршрутам и находите секретный мир.

**Комментарий модератору:**

> Приложение не использует стороннюю авторизацию и не собирает персональные данные.
> Игровой прогресс хранится отдельно для Одноклассников и синхронизируется штатным
> хранилищем VK Bridge. Все переходы к связанным играм выполняются внутри платформы
> через VKWebAppOpenApp; внешние VK- и DonationAlerts-ссылки в OK отключены.

## Контрольный сценарий

1. Первый запуск открывает «Домино: Границы» и кузнечную заставку.
2. Свайп, колесо и стрелки переключают миры без выхода из приложения.
3. Нагрев ядра открывает случайный портал; обложка и название назначения совпадают.
4. После телепортации прогресс повышает требуемое число ударов и сохраняется.
5. На другом устройстве того же пользователя OK прогресс восстанавливается.
6. Двойное касание карточки вызывает `VKWebAppOpenApp`, а не внешний URL.
7. При недоступном дочернем приложении показывается сообщение внутри Wanderhaym.
8. В OK нет активных ссылок на VK, GitHub или DonationAlerts.

## Известные блокеры до подачи

- Нужны одобренные URL сообщества и поддержки в OK.
- Нужно подтвердить соответствие текущего аватара требованиям 576 × 576.
- Нужно выбрать платформенную монетизацию или согласовать статус промо-приложения.
- Нужны реальные проверки после включения OK-публикации в кабинете: локальный параметр
  `vk_client=ok` проверяет адаптацию интерфейса, но не заменяет тест внутри клиентов OK.
