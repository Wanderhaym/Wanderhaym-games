# 🎮 Мои игры — Wanderhaym Games

Коллекция VK мини-игр от Wanderhaym. Сайт-витрина всех мини-приложений:
тесты на совместимость, головоломки, генератор идей и многое другое.

🔗 **Живой сайт:** <https://wanderhaym.github.io/Wanderhaym-games/>

## Что это

«Мои игры» — это статический лендинг, который показывает список VK мини-игр.
Каждая карточка ведёт на соответствующее приложение внутри ВКонтакте
(`https://vk.com/app{id}`).

## Технологии

- Чистый HTML / CSS / JavaScript (без сборщиков)
- GitHub Pages для хостинга
- GitHub Actions для автоматического деплоя

## Структура

```
.
├── index.html                # Лендинг (главная страница)
├── assets/
│   ├── css/styles.css        # Стили
│   └── js/
│       ├── main.js           # Рендер карточек игр
│       └── games-data.js     # Данные мини-игр (appId, title, description, icon)
└── .github/
    └── workflows/
        └── deploy.yml        # Публикация на GitHub Pages
```

## Локальный запуск

Сайт статический — достаточно открыть `index.html` в браузере или запустить
простой сервер:

```bash
npx serve .
```

## Как добавить новую игру

1. Открой `assets/js/games-data.js`.
2. Добавь объект в массив `window.GAMES_DATA`:

```js
{
  appId: 12345678,              // ID приложения ВКонтакте
  title: 'Название игры',
  description: 'Короткое описание',
  icon: 'https://.../icon.jpg', // ссылка на иконку
  tag: 'Категория',
}
```

3. Закоммить и запушь — сайт обновится автоматически.

## Деплой

Публикация настроена через GitHub Actions. При каждом пуше в ветку `main`
рабочий процесс собирает статику и разворачивает её на GitHub Pages.
