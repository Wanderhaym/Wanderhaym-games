# Wanderhaym Games — cinematic WebGL experience

Интерактивная 3D-витрина мини-игр Wanderhaym. Пользователь путешествует камерой
между отдельными игровыми мирами, разогревает огненное ядро, собирает лапу-портал
и запускает выбранную игру внутри ВКонтакте или Одноклассников. Одиннадцатый мир
открывается как секрет.

## Что находится в сцене

- реальная `Three.js Scene` и `PerspectiveCamera`;
- отдельные Camera Journey-маршруты и сцены прибытия для разных миров;
- лапа-портал, которая равномерно собирается по мере нагрева ядра;
- случайное направление телепорта и секретный мир после серии переходов;
- WebGL fluid simulation с advection, curl, divergence, pressure и несколькими splat-импульсами;
- procedural GPU fire core с ударной волной и реакцией на молот маскота;
- GPU-анимированные искры, огненная мантия и частицы окружения;
- bloom, chromatic displacement, grain, цветокоррекция мира и cinematic transition shader;
- яркие unlit/sRGB-обложки в объёмных металлических порталах;
- утверждённая покадровая анимация рисованного кота с прозрачным фоном;
- кузнечная загрузочная сцена с гарантированным первым ударом и морганием кота;
- аудиореактивное ядро на основе Web Audio analyser;
- спокойный режим эффектов и скрытый перегрев ядра при удержании;
- адаптивные high/medium/low профили для desktop и mobile.

## Локальная разработка

Актуальная заставка — **Wanderhaym Loader 1.0.2**, общая для сайта и VK Mini App.
Подключение, синхронизация утверждённых файлов и проверки описаны в
[`docs/LOADER.md`](docs/LOADER.md).

```bash
npm install
npm run dev
```

Проверка и production-сборка:

```bash
npm run typecheck
npm run build
npm run preview
```

Готовая сборка создаётся в `dist/`. Публикация выполняется GitHub Actions после
push в `main`; до финальной проверки изменения можно полностью тестировать
локально без обновления публичного сайта.

## Одноклассники

OK-версия определяется по параметру `vk_client=ok`. В ней внешние ссылки
отключаются, Mini Apps открываются через `VKWebAppOpenApp`, а прогресс портала
хранится отдельно и синхронизируется через VK Bridge Storage. Перед модерацией
используется внутренняя группа Wanderhaym в ОК; параметры из `.env.example`
позволяют позднее заменить её для поддержки. Пройдите контрольный список:
[`docs/OK_MODERATION.md`](docs/OK_MODERATION.md).

## Управление

- колесо мыши, стрелки клавиатуры или кнопки — переход между мирами;
- свайп — навигация на сенсорном экране;
- движение указателя — жидкая FBO-деформация и camera parallax;
- пробел или короткий клик по свободной области — удар молота;
- клик по активной обложке — запуск VK Mini App.
